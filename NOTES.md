## 1. приложение может не подняться при первом запуске

шаги воспроизведения: docker compose down -v && docker compose up -d --build на чистом окружении, подождать немного и проверить docker compose ps

ожидаемое поведение: все сервисы поднимаются и остаются в статусе up

фактическое поведение: иногда app оказывается в статусе exited. помогает docker compose up -d app повторно. похоже на гонку состояний, когда app стартует раньше, чем база данных готова принимать подключения

## 2. форма перевода не всегда показывает ошибку валидации номера

шаги воспроизведения: открыть форму перевода, оставить все поля пустыми, нажать "send"

ожидаемое поведение: должно появиться сообщение об ошибке под полем номера телефона "phone number is required"

фактическое поведение: никакого сообщения не появляется, вместо этого браузер показывает всплывающую подсказку по одному из других полей. сообщение "phone number is required" появляется, только если сумма и назначение уже заполнены, а поле номера пустое, либо если кликнуть в поле номера и увести фокус

## 3. нет проверки регистрации пользователя

шаги воспроизведения: залогиниться, выполнить перевод на любой номер в правильном формате, который точно не принадлежит пользователю

ожидаемое поведение: должна появиться ошибка о том, что получатель не найден

фактическое поведение: перевод проходит успешно, баланс отправителя уменьшается

## 4. в транзакциях перепутаны местами колонки type и status

шаги воспроизведения: открыть /transactions и посмотреть на таблицу

ожидаемое поведение: под колонкой "operation type" должен быть тип операции: "deposit" или "withdrawal". под колонкой "operation status" статус: "completed" или "pending"

фактическое поведение: значения отображаются в неправильных колонках. под "operation type" показывается статус, а под "operation status" тип операции

## 5. ввод очень большой суммы в "add balance" разлогинивает пользователя

шаги воспроизведения: залогиниться, перейти на /transactions, открыть "add balance", ввести очень большое число, подтвердить. после этого повторить операцию ещё раз с ещё одной большой суммой

ожидаемое поведение: либо сумма успешно добавляется к балансу, либо появляется ошибка к примеру: "слишком большая сумма на балансе", пользователь остаётся в системе

фактическое поведение: пользователя выкидывает из аккаунта

требует дополнительной проверки: воспроизвести стабильно через тест, зафиксировать точный порог, при котором это начинает происходить
