# F2F Bank Tests

Проект с e2e тестами для F2F Bank. F2F Bank - простое веб-приложение, имитирующее сервис переводов между пользователями в стиле СБП. Пользователи могут регистрироваться, входить в систему, пополнять баланс и отправлять переводы по номеру телефона

## Как запустить приложение

### Быстрый старт для Linux (i use arch btw)

```bash
curl -fsSL https://raw.githubusercontent.com/FoXeNe/f2f_bank_tests/main/setup.sh | bash
```

### Запуск из исходников

```bash
git clone https://github.com/FoXeNe/f2f_bank_tests
cd f2f_bank_tests
docker compose up -d --build
npm install
npm run test
```

Приложение будет доступно по адресу http://localhost

## Как запустить тесты

Требования: Node.js, Docker с запущенным приложением

```bash
npm install
npm run test # запуск всех тестов
npm run ui   # запуск тестов в UI
```

Дополнительно:
- Файл .env заполнять не нужно, тестовый пользователь создаётся автоматически перед прогоном, а storageState сохраняется в playwright/.auth/user.json

## Описание сценариев и приоритеты

### login.spec.ts

| Важность | Название теста |
| --- | --- |
| Критический | успешный вход с правильными данными |
| Высокий | ошибка при неверном пароле |
| Средний | редирект авторизованного пользователя |
| Средний | форма не отправляется с пустыми полями |
| Средний | форма не отправляется с некорректной почтой |
| Средний | вход с несуществующим пользователем |

### register.spec.ts

| Важность | Название теста |
| --- | --- |
| Критический | успешная регистрация нового пользователя |
| Средний | переход на страницу регистрации с главной |

### home.spec.ts

| Важность | Название теста |
| --- | --- |
| Критический | трансфер с заполненными полями |
| Критический | смена баланса после успешного трансфера |
| Высокий | ошибка при недостаточном балансе |
| Средний | не отправляется форма с пустыми полями |
| Средний | нажатие кнопки нового трансфера после успешного трансфера |
| Средний | ошибка при сумме перевода <= 0 |
| Низкий | ошибка Phone Number при заполненных Amount и Purpose |
| Низкий | ошибка Phone Number при отведении фокуса с поля Phone Number |
| Низкий | ошибка при неверном формате телефона |

### navBar.spec.ts

| Важность | Название теста |
| --- | --- |
| Критический | логаут при нажатии на кнопку |
| Высокий | редирект на страницу main при нажатии на кнопку |
| Высокий | редирект на страницу profile при нажатии на кнопку |
| Высокий | редирект на страницу transactions при нажатии на кнопку |

### profile.spec.ts

| Важность | Название теста |
| --- | --- |
| Средний | совпадает ли username с введенным |
| Средний | совпадает ли surname с введенным |
| Средний | совпадает ли email с введенным |

### transactions.spec.ts

| Важность | Название теста |
| --- | --- |
| Критический | успешное пополнение баланса |
| Высокий | корректное отображение формата времени транзакции |
| Высокий | корректное отображение Type и Status |
| Высокий | ввод 9 100 раз |
| Средний | пополнение баланса с отрицательным значением |
| Средний | пополнение баланса с нулевым значением |
